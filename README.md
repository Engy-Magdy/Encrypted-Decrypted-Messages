# 🔐 Caesar Cipher

A Python application that encrypts and decrypts messages using the Caesar Cipher algorithm.

---

## 📖 About

This project was developed to practice Python programming by applying functions, loops, conditional statements, and string manipulation in a real-world application.

The program allows users to encrypt or decrypt messages using a custom shift value while preserving uppercase letters, lowercase letters, spaces, numbers, and symbols.

---

## ✨ Features

- 🔒 Encrypt text
- 🔓 Decrypt text
- 🔢 Custom shift value
- 🔤 Supports uppercase and lowercase letters
- 💬 Supports complete sentences
- ✨ Preserves spaces, numbers, and symbols
- 🖥️ Simple command-line interface

---

## 🛠️ Technologies Used

- Python
- Functions
- Loops
- Conditional Statements
- String Module
